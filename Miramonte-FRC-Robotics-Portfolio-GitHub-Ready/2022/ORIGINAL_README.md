# FRC2022
Miramonte's software and resources for the 2022 FIRST Robotics Competition.   
There is a Command Robot directory which houses the code for a robot built using the pre-made command robot template.
There is also a Timed Robot directory which houses the code for a robot built using the pre-made timed robot template.
